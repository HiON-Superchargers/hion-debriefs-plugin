# hion-debriefs

The Claude Code plugin for HiON's Debriefs board on Monday: the `/debriefs` skill (check · answer ·
new · ingest) and a band above the prompt that shows how many debrief questions are waiting for you.

Install, at the prompt of a Claude Code session (Claude Code 2.1.287 or newer):

    /plugin install hion-debriefs --marketplace HiON-Superchargers/hion-debriefs-plugin

Update later with `claude plugin update hion-debriefs@hion`.

The protocol it follows is the Monday doc "Debriefs · Protocol" in the HFG HQ workspace; when the
two disagree, the doc wins.
